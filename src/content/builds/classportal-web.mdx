In November 2026 I shipped ClassPortal Web. It is a web app for dance-school-style programs that run more than one school: class scheduling, attendance, and invoicing. I built it with AI coding agents.

The live app is [classportal-web-production.up.railway.app](https://classportal-web-production.up.railway.app).

## Who it is for

Three roles use it: a website admin, school admins and teachers, and families.

## What it does

A session can be accepted or declined, and the confirmation shows on a calendar. Attendance gets taken. Invoice emails go out.

Invites and password resets are email too. Each school sets the sender name and the reply-to on those messages.

The language toggle is English, Chinese, and Spanish. A test fails when a translation is missing. The design is kid-friendly, and the tooltips are accessible.

## Ask ClassPortal

The assistant is called Ask ClassPortal. Grok is the default. OpenAI or Anthropic can be used instead. It is there for sales and for guidance.

"Take me there" highlights the field you asked about. Lookups are read-only, and they stay inside the role and the school of the person asking. There is a setup checklist, and a place to capture a lead.

I put limits on it. Requests are rate-limited. Chats are kept for 30 days, and there is an admin page for them. If no API key is set, it searches the help docs instead of calling a model.

## How it is put together

The front of it is Next.js 15, React 19, and TypeScript, styled with Tailwind v4. Data is Prisma on SQLite. Sign-in is a custom session: bcrypt for passwords, hashed tokens for the session. Changes go through server actions checked with zod, and queries are scoped to the role and the school.

It runs on Railway, in Docker, on Node 22, with a persistent volume. Email goes through Resend or SMTP. The tests are vitest.

## What I learned

I got to take a product the whole way: scheduling, attendance, invoices, email, languages, and a live URL. Ask ClassPortal is the applied LLM piece, and the guardrails are part of the product: rate limits, 30 days of chat, an admin page, read-only lookups scoped to a role and a school, and help-doc search when no API key is set. More than one school means the data has to say which school a row belongs to. Three languages count because a missing translation fails a test. I shipped it with AI coding agents.
