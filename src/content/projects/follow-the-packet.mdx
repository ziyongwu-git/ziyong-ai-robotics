An agent that wants help from another agent has to send something on a wire. This page is that wire, slowed down. You pick a question, and a packet moves from a client to an Agent Card, into an A2A task, through a tool call, and back as an artifact.

The longer explanation, including the Python that does this for real, is the note [How agents talk to agents](/learning/how-agents-talk).

## What this page actually runs

Nothing is trained and nothing leaves the browser. There is no model and no API key. A handful of regular expressions read the question. A list of eight invented clinics answers it. The JSON in the side panel follows the shapes I checked for A2A 1.0 and for an MCP `tools/call`, and the panel says when a hop is only inside the agent.

What it keeps:

- The order of a real call. Card first, then `SendMessage` or `SendStreamingMessage`, then the task states, then the tool, then the artifact.
- A streaming switch. Off, the client waits and gets one response. On, the same work is a series of server-sent events.
- A card description you can edit. A mock orchestrator scores that sentence against two other cards. A vague sentence gets the clinic agent skipped.

What it drops:

- A model. "A cardiologist in Tucson" returns an empty list because the directory has no such row, not because a model decided to be careful.
- Discovery beyond one card. The well-known path is written out. Nothing is fetched.
- Push notifications. The card in the panel says they are off.

## How I built it

The page is this file. The widget is `src/components/demos/FollowPacket.tsx`, loaded with `client:load`. The questions, the directory, the hop JSON, and the toy router live in `src/components/demos/packet.ts`, so the drawing file stays about drawing. `scripts/check-packet.ts` re-runs those rules without a browser.

Colors use the site's CSS variables, so the light and dark themes both apply. If the browser asks for reduced motion, Play stays off and the packet jumps to the next hop instead of sliding.

The runnable agent, with a real MCP server and a real A2A SDK, is `examples/a2a-mcp-doctor-finder`. It uses the same eight clinics. It is not part of `npm run build`.
